# Assets フォルダの利用ガイド

このフォルダ（`assets/`）には、スライドや資料で使用する画像アセットを配置します。

---

## 著作権および公式素材の配置について

本テンプレートリポジトリは、**GitHub 上で Template Repository として公開（Public）することを前提としているため、公益財団法人ボーイスカウト日本連盟の著作物・商標（連盟章ロゴ、公式マニュアル挿絵、公式壁紙画像など）は一切同梱していません。**

セッションで公式ビジュアル素材を使用したい場合は、**利用規約を遵守した上で、各指導者が正規の手順でダウンロードし、このフォルダに配置**してください。

本リポジトリでは、以下のコマンドを実行することで、日本連盟公式 PR ツールから公式壁紙やロゴを一括でダウンロードできます（`.gitignore` により Git コミット対象外となっています）：

```bash
# 公式素材の一括取得
make assets

# 公式素材の削除（初期のダミー状態へ復元）
make clean-assets
```

### 公式素材・PC壁紙画像の対応表

日本連盟公式の「[PRツールダウンロードセンター](https://www.scout.or.jp/member/download/pr-tool)」等から公式壁紙やロゴを入手し、以下のファイル名でこのディレクトリに配置すると、Marpスライドの部門別背景クラス等で自動的に読み込まれます。

| 部門 | 配置ファイル名の例 | 対応するスライドクラス | 未配置時のフォールバック |
| :--- | :--- | :--- | :--- |
| **共通・ボーイスカウト** | `PCWall_2880x1864_BS.jpg` | `section.lead-bs` または `section.lead` | `dummy-bg.svg` または緑グラデーション |
| **ビーバースカウト** | `PCWall_2880x1864_BVS.jpg` | `section.lead-bvs` | 水色グラデーション |
| **カブスカウト** | `PCWall_2880x1864_CS.jpg` | `section.lead-cs` | 黄〜オレンジグラデーション |
| **ベンチャースカウト** | `PCWall_2880x1864_VS.jpg` | `section.lead-vs` | 茜色グラデーション |
| **ローバースカウト** | `PCWall_2880x1864_RS.jpg` | `section.lead-rs` | 藍色グラデーション |

> [!NOTE]
> 公式画像が配置されていない場合でも、テンプレート内の `dummy-bg.svg` および CSS のフォールバック色により、ビルドエラーを起こすことなく正常にスライドが生成されます。

### 連盟章・ロゴマークの利用について
- 日本連盟のロゴマークや記章類の画像を使用する場合は、日本連盟の「記章規程」およびブランドガイドラインを必ず遵守してください。
- 作成した講習資料等を外部（インターネット上）へ公開・再配布する際は、権利関係に十分ご注意ください。
