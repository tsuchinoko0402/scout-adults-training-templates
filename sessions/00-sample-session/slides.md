# セッション展開タイムライン

本セッションの標準的な進行スケジュールです。

| 時間 | 段階 | 主な学習項目・進め方 | 受講者の活動 |
| :---: | :--- | :--- | :--- |
| **00 - 05分** | 導入 | ねらいの提示、現状の課題意識の共有 | 自身の隊の現状を想起 |
| **05 - 20分** | 講義 | 〇〇に関する基本講義（3つのポイント） | 配布資料へのメモ |
| **20 - 35分** | 討議 | ケーススタディ検討・グループワーク | 個人記入 ＋ 班内討議 |
| **35 - 42分** | 共有 | 代表班による発表・全体フィードバック | 多様な視点の共有 |
| **42 - 45分** | まとめ | 総括と自隊での実践アクション宣言 | アクションシート記入 |
